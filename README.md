# Dumpert tools

Stuff that helps navigate the Dutch video sharing site [dumpert.nl](https://www.dumpert.nl/). At the moment this only contains one script and it is very unlikely more things will be added.

## [Worst video](worst_video.py)

This script finds the worst rated videos in a given month on [dumpert.nl](https://www.dumpert.nl/). Users can plus or minus videos. Usually ragebaitvideos are rated negatively, which is exactly what this script is intended to find.

The script is written so it can work nicely with the Jupyter code cells in VS Code. Use the Jupyter extension to run this cell by cell.
